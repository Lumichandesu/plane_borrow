# ✈️ SkyChauffeur - Airplane Borrow & Fleet Management System (Standalone Mock Web App)

ระบบบริหารจัดการและยืม-คืนเครื่องบิน เวอร์ชัน **Modern Standalone Web Application** พัฒนาขึ้นด้วย HTML5, CSS3 และ JavaScript (ES6) พร้อมระบบจำลองข้อมูล (Mock Data) และเก็บสถานะลงใน LocalStorage ในตัว

ไม่ต้องติดตั้ง **Flutter**, **Android SDK**, **Java/Gradle**, **Node.js** หรือ **MySQL** ให้ยุ่งยาก สามารถเปิดใช้งานและนำเสนอผลงานได้ทันที!

---

## 🚀 วิธีการเปิดใช้งาน (How to Run)

เลือกใช้งานได้ง่ายๆ 2 วิธี:

### วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์ได้ทันที (แนะนำ)
* เข้าไปที่โฟลเดอร์ `D:\Projects\plane-borrow-web`
* ดับเบิลคลิกที่ไฟล์ **`index.html`** เพื่อเปิดผ่าน Google Chrome, Edge หรือเบราว์เซอร์ใดก็ได้

### วิธีที่ 2: รันผ่าน Local HTTP Server (ถ้าต้องการ)
```bash
cd D:\Projects\plane-borrow-web
python -m http.server 8080
# จากนั้นเปิดเบราว์เซอร์ไปที่ http://localhost:8080
```

## 👥 บทบาทและการทดสอบระบบ (Roles & Features)

ที่แถบด้านบนของหน้าเว็บ (Header) มีปุ่มลัดสำหรับสลับบทบาทได้ทันที:

1. **🎓 Student (นักศึกษา / ผู้ขอยืม)**:
   - **Fleet Catalog**: ดูรายการเครื่องบินทั้งหมด พร้อมรูปภาพจริง ข้อมูลสเปก ที่นั่ง และสถานะ (พร้อมใช้งาน / ถูกยืมอยู่)
   - **ขอยืมเครื่องบิน**: กดปุ่ม *"ขอยืมเครื่องบินลำนี้"* เลือกวันที่เริ่มยืม - กำหนดส่งคืน และระบุวัตถุประสงค์การบิน
   - **My Requests**: ตรวจสอบสถานะคำขอ (รอพิจารณา / อนุมัติแล้ว / ไม่อนุมัติ) พร้อมปุ่มยกเลิกคำขอ
   - **History**: ดูประวัติการบินและการคืนเครื่องบิน

2. **👨‍🏫 Lecturer (อาจารย์ผู้อนุมัติ)**:
   - **Pending Requests**: ตรวจสอบคำขอที่นักศึกษาส่งมา พร้อมปุ่ม **✓ อนุมัติ** หรือ **✗ ปฏิเสธ**
   - **Fleet Status**: ดูภาพรวมความพร้อมของเครื่องบินทุกลำในสังกัด
   - **Approval Log**: บันทึกประวัติการอนุมัติย้อนหลัง

3. **🛠️ Staff (เจ้าหน้าที่ผู้ดูแลฝูงบิน)**:
   - **Fleet CRUD**: จัดการเครื่องบิน เพิ่มเครื่องบินใหม่ (`+ เพิ่มเครื่องบินใหม่`), แก้ไขข้อมูล หรือลบเครื่องบิน
   - **Return Processing**: ตรวจรับและกด **✓ บันทึกรับคืนเครื่องบิน** เมื่อนักศึกษานำเครื่องบินมาส่งคืน สถานะจะถูกเปลี่ยนกลับเป็น "พร้อมใช้งาน" อัตโนมัติ
   - **Fleet Analytics**: แดชบอร์ดสรุปสถิติจำนวนเครื่องบิน อัตราการยืม และภารกิจสะสม
   - **Audit Logs**: บันทึกประวัติการยืม-คืนทั้งระบบ
